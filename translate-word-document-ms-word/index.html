Microsoft Word Translation Guide

How to Translate a Word Document Automatically & Manually

Learn how to translate text or an entire Microsoft Word document using built-in Word translation tools on Windows 10 and Windows 11.

Published: December 3, 2024

Translate a Microsoft Word Document

Microsoft Word includes translation tools that can help convert selected text or document content from one language to another.

This can be useful when working with documents received in another language or when preparing multilingual content.

Automatic Word Document Translation

In supported versions of Microsoft Word, the translation tools are available from the Review area of the Ribbon.

Depending on the Word version and Microsoft 365 configuration, you may see options for translating selected text or translating the document.

Translate Selected Text in Microsoft Word

  1. Open the Word document.
  2. Select the text you want to translate.
  3. Open the Review tab.
  4. Select Translate.
  5. Choose the source and destination languages.
  6. Review the translated text.

Translate an Entire Word Document

Where the option is available, Word can create a translated copy of the document.

Review the translated document carefully, especially when the original document contains technical, legal, medical or specialized terminology.

Manual Word Translation

You can also translate smaller sections individually and manually replace the original text.

This approach can provide better control when only certain sections need translation or when formatting must be preserved carefully.

Check Important Translations

Automatic translation can misunderstand context, names, technical terms or specialized language.

Review important translations before using them professionally.

Microsoft Word Translation Frequently Asked Questions

Can Word translate a document automatically?

Supported versions of Microsoft Word include translation tools that can assist with translating selected text and document content.

Can Word translate only selected text?

Yes. Select the text first and then use the Translate option where supported.

Do I need Microsoft 365?

Feature availability varies by Office version, licensing and configuration. Check the translation options available in your installed Word version.

Is automatic translation always correct?

No. Important translated content should always be reviewed for accuracy and meaning.
