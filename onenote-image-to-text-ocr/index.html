Microsoft OneNote OCR Guide

How to Copy Text from Image in OneNote | JPG to Text OCR Trick

Learn how to use Microsoft OneNote OCR to recognize and copy text from JPG images, screenshots, scanned documents and other pictures without manually typing all of the text.

Published: December 14, 2025

Copy Text from an Image Using OneNote

Microsoft OneNote includes Optical Character Recognition, commonly called OCR. OCR can recognize text contained inside an image and convert the recognized characters into text that you can copy.

This can save time when information is available only as a picture, screenshot or scanned document.

Convert JPG Image to Text with OneNote OCR

If you have a JPG containing text, insert the picture into OneNote. OneNote can analyze readable text inside the picture and provide an option to copy the recognized text.

You can then paste the copied text into applications such as Microsoft Word, Notepad, email or another OneNote page.

How to Extract Text from a Picture in OneNote

  1. Open Microsoft OneNote.
  2. Create or open a OneNote page.
  3. Insert the JPG, PNG, screenshot or other supported image.
  4. Allow OneNote time to process the image if necessary.
  5. Right-click the inserted picture.
  6. Select the option to copy text from the picture when available.
  7. Paste the recognized text into the application where you need it.
  8. Review the extracted text for OCR recognition errors.

Copy Text from Screenshots

OneNote OCR can also be useful when text appears inside a screenshot. Instead of manually retyping information, insert the screenshot into OneNote and use OCR to recognize the visible text.

OCR accuracy depends on the quality, resolution, font, language, contrast and clarity of the original image.

Common Uses for OneNote OCR

  • Copy text from JPG images
  • Extract text from screenshots
  • Convert picture text into editable text
  • Copy information from scanned documents
  • Extract text from an image without manually typing it
  • Move recognized text into Microsoft Word
  • Use OCR on Windows
  • Convert image information into reusable text

What Does OCR Mean?

OCR stands for Optical Character Recognition. It is technology used to detect characters and words contained in images and convert them into machine-readable text.

The original picture remains an image. OCR creates recognized text from the visible characters inside that image.

Always Check OCR Results

OCR is not guaranteed to recognize every character correctly. Blurry images, unusual fonts, handwriting, low resolution and poor contrast can produce recognition errors.

Always compare important extracted information with the original image before using it.

Microsoft OneNote OCR Frequently Asked Questions

Can OneNote copy text from an image?

OneNote can use OCR to recognize readable text contained in supported images and make that recognized text available for copying.

Can I convert JPG to text with OneNote?

If the JPG contains clear readable text, OneNote OCR can help recognize the characters so the resulting text can be copied.

Why is Copy Text from Picture not available?

The option may depend on the OneNote version, image processing, image type and whether OneNote has completed OCR processing.

Is OCR always accurate?

No. Recognition quality depends on the source image, so important information should always be checked against the original picture.
