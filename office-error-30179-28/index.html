Office Error 30179-28: Not Enough Disk Space Fix

A step-by-step Windows 11 and Windows 10 guide for Microsoft 365 installation error 30179-28.

What causes Error 30179-28?

This Microsoft 365 installation error can appear when the Windows system drive, usually C:, does not have enough usable free space for Office to download, extract and install its files.

This guide shows how to:

  • Check C: drive free space.
  • Confirm available disk space using Command Prompt.
  • Open Windows Temporary Files.
  • Review files before deleting them.
  • Clear the Recycle Bin and temporary folders.
  • Restart the Microsoft 365 installation.

Commands used

wmic logicaldisk get caption,freespace,size

fsutil volume diskfree C:

echo %ProgramFiles%

echo %ProgramFiles(x86)%

echo %TEMP%

Important safety warning

Do not select the Downloads category until you have reviewed and backed up the files stored there. Also check the Recycle Bin before permanently deleting anything.
