WhatsApp Stop Working on Old iPhones? Check iOS Version Now

Learn how to check whether an older iPhone can continue using WhatsApp, how to update iOS, what to do if the phone cannot update, and how to back up WhatsApp chats before moving to another device.

Why WhatsApp may stop working on an old iPhone

WhatsApp periodically updates its operating-system requirements to support newer security, privacy and application features. Older iPhones may eventually lose support if they cannot install the minimum required iOS version.

Check your iPhone iOS version

Open:

Settings → General → About

Look for the current iOS version and compare it with the minimum version required by WhatsApp.

Check for an iOS update

Open:

Settings → General → Software Update

If an update is available, connect the iPhone to Wi-Fi and power before installing it.

If the iPhone cannot update

If the device cannot install the required iOS version, WhatsApp may eventually stop opening or receiving updates. In that situation, you may need to move WhatsApp to a newer supported phone.

Back up WhatsApp chats before changing phones

Open WhatsApp and go to:

Settings → Chats → Chat Backup → Back Up Now

Confirm that iCloud is enabled and that enough iCloud storage is available before starting the backup.

Android users

Android devices also have minimum system requirements. Check the Android version in the phone settings and install available system updates before WhatsApp support changes take effect.
