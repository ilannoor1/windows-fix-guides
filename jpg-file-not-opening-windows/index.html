Windows Photos Troubleshooting

JPG File Not Opening? Fix Windows 11 & Windows 10 Photos Error

Troubleshoot JPG and JPEG images that will not open in Microsoft Photos on Windows 11 or Windows 10 and check whether the problem is caused by the Photos app, file association or the image itself.

Published: May 18, 2025

JPG File Not Opening in Windows

If you double-click a JPG or JPEG image and nothing happens, Microsoft Photos displays an error, or Windows asks you to choose an application, first determine whether the problem affects one image or every image.

  • JPG Not Opening
  • Microsoft Photos Error
  • Windows 11 / Windows 10

1. Test Another JPG or JPEG Image

Before changing Windows settings, open several different JPG files.

If only one image fails while other images work normally, the individual file may be damaged or use unexpected content despite having a JPG extension.

2. Try Open With

Right-click the image and choose Open with. Then select Microsoft Photos or another trusted image viewer.

If the picture opens correctly in another application, the image itself may be fine and the problem may instead involve Microsoft Photos or the current file association.

3. Check the Default App for JPG Files

Windows uses file associations to determine which application opens a particular file type.

Open Windows Settings and review the Default Apps configuration for .jpg and .jpeg.

Select Microsoft Photos or another compatible image viewer if the file association is incorrect.

4. Repair Microsoft Photos

If Microsoft Photos itself is not working correctly, Windows may provide a Repair option for the application.

  1. Open Windows Settings.
  2. Open Apps.
  3. Find Microsoft Photos.
  4. Open its advanced application options where available.
  5. Select Repair.
  6. Test the JPG file again.

Repair is generally preferable before using the more disruptive Reset option.

5. Reset Microsoft Photos If Repair Does Not Work

If Repair does not solve the problem, Windows may also provide a Reset option.

Repair First, Reset Second

Resetting an application can remove its local app data and settings. Read the Windows warning shown on your PC before continuing.

6. Check Microsoft Photos and Windows Updates

If the issue continues, check for updates to Microsoft Photos and Windows.

Application or operating-system updates can resolve known problems affecting supported image formats and application behaviour.

7. Check Whether the JPG File Is Corrupted

If the same image fails in several different image viewers or on another computer, the image itself may be damaged.

If possible, compare the file size, restore another copy from the original device or backup, or download the original image again.

Do Not Delete the Original Image

If the JPG contains important photos or documents, keep the original file while troubleshooting.

Test repairs on a copy when possible, especially if you suspect file corruption.

JPG & Microsoft Photos Frequently Asked Questions

Why won't my JPG open in Windows 11?

Check whether other JPG images open normally. If all JPG files fail, investigate Microsoft Photos and the JPG file association. If only one file fails, investigate that individual image.

Should I reset Microsoft Photos?

Try Repair first where available. If Repair does not work, Reset can be considered after reading the Windows warning about application data and settings.

Why does my JPG open in another program but not Photos?

That can indicate the image itself is readable while Microsoft Photos or its Windows configuration needs troubleshooting.

Can changing the default app fix JPG files?

It can fix situations where Windows has an incorrect or broken file association for JPG or JPEG files.
